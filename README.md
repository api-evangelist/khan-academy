# Khan Academy (khan-academy)

Khan Academy is a non-profit providing free online educational content. The legacy Khan Academy API (v1) is deprecated/limited and the public api-explorer.khanacademy.org redirects to the main site. Some endpoints under www.khanacademy.org/api/v1/ remain in use for internal apps and historical integrations, but Khan Academy no longer maintains a publicly supported developer program.
